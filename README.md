# Guia de Boas Práticas - InovaWeb

**Autor:** Luis Felipe Soares Costa

## Sobre o projeto

Este guia reúne orientações para ajudar os clientes da InovaWeb a utilizarem a internet de maneira mais segura e produtiva.

O material apresenta dicas de segurança digital, ferramentas úteis e informações de suporte para facilitar o dia a dia dos usuários.

## Conteúdo

- `dicas-seguranca.md` — Cuidados com senhas e navegação segura.
- `ferramentas-uteis.md` — Sites e aplicativos gratuitos para produtividade e estudos.
- `contatos-suporte.txt` — Canais de atendimento da agência.
